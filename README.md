## 소개
공공 데이터를 연결해서 GPS 기반 먹거리, 문화 행사, 주차장 정보를 제공하는 웹앱 형태의 사이트 제작

## 목적
지역 먹거리, 문화 행사 등에 대한 정보를 제공하고 위치 정보과 근처 주차장 정보를 제공함으로써 여행 지역에 대한 관광객의 즐거움 선사 및 지역 활성화

## 페이지 소개
1. 로딩 페이지: GIF로 로딩 페이지 구현 > 로딩이 완료되면 Start 버튼 활성화되고 문이 열려 입장하듯이 사이트 메인으로 이동
2. 메인 페이지: 업데이트 필요(내용 구현 미설정)
3. 먹거리 페이지: 주요 지역별 먹거리를 카드로 먼저 안내하며, 해당 식당에 대한 상세 정보를 리스트로 구현 + 관광객이 먹고 싶은 음식 종류에 따라 필터링 구현
4. 문화/행사 페이지: 주요 행사 정보를 이미지와 함께 카드로 안내하면서 상세 내용에 대해 테이블을 통해 리스트로 구현 (빠른 검색을 위한 검색창 구현 - 기능 미구현, 업데이트 예정)
5. 주차 페이지: 지도를 통해 현재 내 위치 정보를 시각적으로 확인하고, 관련 주차장 정보를 아래 테이블 목록에서 확인 (GPS 기반 필터링 기능 구현 예정 > 현재는 주차장 검색을 통한 필터링으로 해둔 상태이나 검색 기능 연결 필요)

## 업데이트 예정 기능 및 페이지
1. 문화/행사 페이지 및 주차 페이지 내 테이블 검색 기능
2. 검색 페이지
3. GPS 기반 주차장 정보 필터링 기능 (해당 기능 구현 시 테이블 검색 기능 삭제 여부 검토)
4. 메인 페이지
